Wyggdrasil

Wyggdrasil is an open-source Python tool for audio analysis. The project includes both a Python script for developers and a standalone Windows executable for users who prefer not to install Python.

Getting Started

  • Windows users — download the .exe from the releases page and run it directly, no installation required.
  • Developers — clone the repository and run the Python script directly.
